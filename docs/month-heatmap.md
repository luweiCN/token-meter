# 菜单栏月历色阶

月历按每日 Token 绝对用量着色，同一用量在不同日期、月份使用同一颜色。区间与颜色的权威定义是 [`MonthHeatmapBand`](../Sources/TokenMeterApp/MonthHeatmapBand.swift)，月历、图例和日期详情共同使用它。

- 零用量单独显示灰色；非零用量保留浅蓝、蓝、青、绿四个低档，以及黄、红两个高档。
- 达到区间下界时进入该档，不以当月最大值或日期排名计算颜色。
- 所有非零档在深、浅主题中都与零用量及面板背景保持可辨识的对比度。
- 月历底部显示完整色带，悬浮色带查看固定区间；日期明细同时显示当天的精确用量与所在档位。
- 未来日期和月外占位不参与分档；未来日期不弹用量明细。

色阶只表达用量级别，不表示错误、额度告警或超预算。统计数据与金额计算由原有数据源和计价规则负责。
