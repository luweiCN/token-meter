# Token 活跃度色阶

菜单栏月历、桌面主界面全年活跃度和移动端用量日历按每日 Token 绝对用量着色。同一用量在同一主题使用同一颜色。

阈值和深浅主题颜色的唯一来源是 [`token-heatmap-bands.json`](../Sources/TokenMeterApp/Resources/token-heatmap-bands.json)。桌面 Swift 和 React 共同读取它，移动端从同一文件生成色阶。

- 零用量单独显示灰色；非零用量保留浅蓝、蓝、青、绿四个低档，以及黄、红两个高档。
- 达到区间下界时进入该档，不以当月最大值或日期排名计算颜色。
- 所有非零档在深、浅主题中都与零用量及面板背景保持可辨识的对比度。
- 桌面悬浮日期查看读数和所在档位。菜单栏月历还显示当日各模型和设备的 Token、花费及缓存命中率。手机点日期查看当天用量和估算费用。正数颜色以已记录的 Token 为准，未知用量单独标记。
- 未来日期和月外占位不参与分档；未来日期不弹用量明细。

色阶只表达用量级别，不表示错误、额度告警或超预算。统计数据与金额计算由原有数据源和计价规则负责。

日 Token 总量按输入、输出、缓存读取及缓存写入相加。思考 Token 已包含在输出中，不再重复累加；月历、日期明细与全年图使用同一计数口径。

菜单栏直接显示有记录的 Token 数。只按积分计费的记录保留原始积分，积分不折算为 Token。点击菜单栏可立即查看最近一次已完成的统计，设备汇总更新后面板自动刷新。[设备统计范围](device-sync.md)

菜单栏弹窗的模型明细与月历的模型和设备明细显示带有 Token、费用、积分或明确缺失标记的条目。仅有日志事件计数的条目计入日期的事件数。

菜单栏的缓存命中率按已记录的输入 Token 加权。分子是缓存读取，分母是普通输入、缓存读取及各档缓存写入的合计。无已记录输入时显示「暂无数据」。日历同时展示悬停日期整体及各模型的命中率，「今日合计」包含折叠的模型，总计、本月和本周按各自日期范围计算。

全年活跃度切换到成本、会话、事件时，仍按对应指标的相对数量级着色，不使用 Token 阈值。
